Project Overview

Goal & Relevance Scheme (Amazon ESCI)

🎯 Problem Statement

E-commerce queries are challenging because customers search using short intent terms while products have verbose titles.

The Amazon ESCI Dataset provides human-annotated relevance judgments categorized into four distinct customer intent levels.

🏷️ The 4 ESCI Relevance Levels

[E] Exact (Gain: 3.0): The item precisely satisfies the query.

[S] Substitute (Gain: 2.0): Functional alternative (e.g. iPhone 13 -> iPhone 14).

[C] Complement (Gain: 1.0): Accessory/add-on (e.g. iPhone 13 -> phone case).

[I] Irrelevant (Gain: 0.0): Completely off-topic result.

Pipeline Design

Text Preprocessing Pipeline (100% From Scratch)

Pipeline Architecture:

1. HTML & Entity Cleaning: Strips tags, decodes &amp;, normalizes Unicode NFKD, lowercases.

2. Alphanumeric Tokenizer: Preserves product specs (e.g. 128gb, 4k, g502).

3. Stop-Word Removal: Prunes high-frequency noise while retaining product intent.

4. Porter Stemming: Reduces inflections (running -> run, headphones -> headphon).

Models

The Four Core Ranking Paradigms

1. TF-IDF (Vector Space Model)

Classical vector space retrieval using Term Frequency × Inverse Document Frequency. High-speed baseline measuring cosine angles between sparse vectors.

2. BM25 (Okapi Probabilistic)

Probabilistic framework with term frequency saturation (k1 = 1.5) and document length normalization (b = 0.75). Gold-standard sparse baseline.

3. Sentence Transformer (Dense)

Encodes queries and catalog into 384-dimensional dense vectors (all-MiniLM-L6-v2). Solves vocabulary mismatch by matching concept semantics.

4. Hybrid (Reciprocal Rank Fusion)

RRF combines BM25 and Dense ranks: RRF(d) = ∑ [ w / (60 + rank(d)) ]. Eliminates score scale mismatch and achieves highest nDCG.
